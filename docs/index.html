Sade bir Arch, hazır kurulumla

Arch'ın esnekliğini koruyan, ama kurulumu ve ilk ayarları sizin yerinize yapan bir başlangıç noktası.

01

Arch tabanlı, kayan sürüm

Arch Linux depolarından güncel paketler. Sistem pacman ile güncellenir, yeniden kurulum gerekmez.

02

KDE Plasma (Wayland)

Tam özellikli masaüstü. Tüm KDE paket yığını değil, yalnızca gerekli parçalar kurulur.

03

CachyOS çekirdeği ve depoları

linux-cachyos varsayılan, Arch çekirdeği yedek. İşlemciniz destekliyorsa optimize (v3/v4) paketler kullanılır.

04

Grafik kurucu

Calamares ile kurulum. Önyükleyici olarak GRUB, BIOS ve UEFI için. UEFI testleri sürüyor.

05

LibreWolf tarayıcı

Gizlilik odaklı, Firefox tabanlı tarayıcı varsayılan olarak gelir.

06

Şeffaf derleme

ISO, GitHub Actions ile üretilir. Tüm yapılandırma açık kaynak ve depoda, istediğiniz gibi değiştirebilirsiniz.

İndir

Taichi Linux'u edinin

ISO imajını indirin, sağlama toplamını doğrulayın ve önce sanal makinede deneyin.

Henüz herkese açık bir ISO yayınlanmadı. ISO'lar GitHub Actions ile derleniyor. Şimdilik aşağıdaki bölümden kendiniz derleyebilirsiniz.

Taichi Linux

Doğrulama (Linux):
sha256sum -c taichi-*.iso.sha256

Kurulum

  1. USB belleğe yazınVentoy, Rufus, balenaEtcher ya da dd ile. Önce sanal makinede denemenizi öneririz.
  2. USB'den başlatınCanlı oturum otomatik açılır. Kullanıcı live, şifre yoktur.
  3. Kurucuyu çalıştırınMasaüstündeki "Taichi Linux'u Kur" simgesine çift tıklayın ve adımları izleyin.
Kaynak

Kendin derle

ISO'yu kendi hesabınızda üretmek için bir bilgisayara kurulum gerekmez.

GitHub Actions ile

Önerilen yol. Kendi bilgisayarınıza hiçbir şey kurmanız gerekmez.

  1. Depoyu fork'layın.
  2. Actions sekmesinde "Build ISO" iş akışını seçin.
  3. "Run workflow" düğmesine basın.
  4. Bitince çalıştırmanın Artifacts bölümünden ISO'yu indirin.

Docker ile (Linux)

Actions'ın yaptığı işin aynısı. Yaklaşık 15 GB boş disk gerekir.

git clone https://github.com/bxiefr/Taichi-Linux.git
cd Taichi-Linux
mkdir -p out
docker run --rm --privileged \
  -v "$PWD":/work -w /work \
  archlinux:latest bash scripts/ci-build.sh
