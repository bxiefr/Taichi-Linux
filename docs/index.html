Öne Çıkan Özellikler

Taichi Linux, kurduğun andan itibaren eksiksiz ve optimize edilmiş bir Masaüstü deneyimi sunmak için tasarlandı.

ArchISO Altyapısı

En güncel Arch Linux tabanı ile resmi paket kaynaklarına doğrudan erişim ve maksimum özelleştirilebilirlik.

KDE Plasma Ortamı

Modern, hızlı ve görsel açıdan zengin bir masaüstü deneyimi için optimize edilmiş varsayılan KDE Plasma entegrasyonu.

Otomatik CI/CD Derleme

GitHub Actions otomasyonu sayesinde sistem her zaman güncel paketlerle otomatik olarak derlenir.

Proje Klasör Mimarisi

Taichi Linux projesinin GitHub üzerindeki resmi dizin yapısı ve bileşenleri.

.github/workflows CI/CD Yapılandırmaları
aur-packages Özel AUR Paket Scriptleri
docs Dokümantasyon & Rehberler
profile ArchISO Profil Dosyaları
scripts Kurulum & Sistem Scriptleri
config.env Sistem Değişkenleri

Modüler & Şeffaf Mimari

Taichi Linux derleme süreci tamamen modüler yapıdadır. `profile` klasörü içerisinden paket listelerini düzenleyebilir, `scripts` dizini üzerinden sistem yapılandırmalarını özelleştirebilirsiniz.

Tam Otomatik Derleme

`.github/workflows/build-iso.yml` dosyası her yeni güncellemede resmi Arch ISO çıktısını sıfırdan oluşturur.

Kendin Derle

İsterseniz Taichi Linux'u kendi sisteminizde archiso kullanarak veya GitHub Actions üzerinde derleyebilirsiniz.

1. Depoyu Klonlayın
git clone https://github.com/bxiefr/Taichi-Linux.git
2. Dizin İçine Girin
cd Taichi-Linux
3. ArchISO ile Derleyin (Root yetkisi gerekir)
sudo mkarchiso -v -w ./work -o ./out ./profile
